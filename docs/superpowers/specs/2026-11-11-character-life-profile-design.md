# 全局角色生活档案

角色库里的新建角色分成两组。固定外貌、固定身材和参考形象跨世界保持原样。其余都是默认值，进入每个世界时单独改写，并在界面上标成「随世界变化」。

## 字段

跨世界不变：

- 固定外貌 `appearance`
- 固定身材 `physique`
- 参考形象 `image_url`，以及已有的 `reference_images`

进入世界后会改变。角色库保存默认值，本局主角保存这一世界的版本：

| 界面 | 角色库默认值 | 本局版本 |
| --- | --- | --- |
| 默认姓名 | `name` | `name` |
| 默认身份 | `role` | `role` |
| 默认性格 | `default_personality` | `personality` |
| 默认价值观 | `default_values` | `values` |
| 默认说话方式 | `default_speech` | `speech` |
| 默认习惯 | `default_habits` | `habits` |
| 默认愿望 | `default_desires` | `desires` |
| 默认恐惧 | `default_fears` | `fears` |
| 默认在乎的人 | `default_relationships` | `relationships` |
| 默认能力 | `default_abilities` | `abilities` |
| 默认经历 | `default_background` | `background` |
| 默认服装 | `default_styling` | `styling` |

「在乎的人」是一段文字，不建关系表。姓名在角色库里是默认名，列表仍按这个名字搜索和展示。进入世界后可以改成当地姓名或称呼。

角色库限制：姓名 80 字，身份 120 字，其余文本 2000 字。本局编辑与现在的性格字段一致，每项 4000 字。生成草稿按角色库的上限截断。

已有全局角色的新列为空。原来的姓名、身份、性格和服装继续作为默认值。

## 存储

`global_characters` 增加 `default_values`、`default_speech`、`default_habits`、`default_desires`、`default_fears`、`default_relationships`、`default_abilities`、`default_background`。新库写在建表语句里，旧库用现有的幂等 `ALTER TABLE` 补列。Drizzle 表定义同步这些列。

`characters` 不增加这些生活细节列。本局主角快照同时保存默认值和本世界版本。默认值的键为 `default_name`、`default_role`、`default_personality`、`default_values`、`default_speech`、`default_habits`、`default_desires`、`default_fears`、`default_relationships`、`default_abilities`、`default_background`、`default_styling`。本世界版本的键为 `name`、`role`、`personality`、`values`、`speech`、`habits`、`desires`、`fears`、`relationships`、`abilities`、`background`、`styling`。`appearance` 和 `physique` 只有一份，没有默认副本。

写回项目角色的仍是现有列：姓名、身份、外貌、身材、性格、经历、服装。外貌和身材写回固定原文。价值观、说话方式、习惯、愿望、恐惧、在乎的人和能力只留在本局快照里，并进入这一局的正文要求。本局保存接口接受上述本世界版本，以及 `appearance` 和 `physique`。

制作台继续使用项目角色上已有的姓名、身份、外貌、身材、性格、经历和服装。不为新的生活细节改制作台表单。

## 开局适配

从角色库选中的主角，先把默认值复制进本局，外貌和身材原句照搬，`adapted` 仍为 false。第一次书写前，文本模型按当前世界改写所有可变项。提示明确要求脸部外貌和身材保持原文，姓名、身份和生活细节可以改变。

模型返回的某一项缺失或不是字符串时，该项保留默认值。整个调用失败时，所有可变项使用默认值，外貌和身材不变。适配不回写全局角色。

开场前如果用户已经手动保存过本局主角，沿用现在的行为：不再自动适配，保留手动内容。

按世界直接生成的主角已经属于那个世界，`adapted` 为 true，不再走第二次适配。生成结果包含同一组生活细节。生成失败时，新字段为空字符串，姓名、身份、经历和服装继续使用现在的兜底。

正文要求列出本世界的姓名、身份、各项生活细节、固定外貌和固定身材。要求写明：脸和身材与固定设定一致；姓名、身份和生活细节使用本世界版本；行为和造型使用本世界的性格、价值观、习惯、愿望、恐惧、关系、经历和服装。

## 定妆图

开局适配只有在服装文本发生变化，且图片是自动生成的时候，才清空自动定妆图并增加 `image_revision`。姓名、身份、性格和其他生活细节的变化不换脸。

本局手动编辑时，只有外貌、身材或服装变化才清空自动定妆图。修改外貌或身材只影响这一局的项目角色，不回写角色库。

## 界面

角色库表单分两段。第一段标题为「跨世界不变」，包含固定外貌、固定身材和现有的参考形象地址。`reference_images` 继续只作为已保存数据，不新增输入框。第二段标题为「进入世界后会改变」，包含上表里的全部默认值，每一项都有可见文字「随世界变化」。段首说明这些是默认值，进入不同世界后会单独改写。全局角色接口使用现有的 snake_case 字段名接收这些默认值。

生成草稿按角色构想填写全部字段。姓名仍然必填；构想为空或草稿没有可用姓名时，沿用现在的中文错误。其余字段可以是空字符串。

游玩页展示本局主角的各个本世界版本。编辑框包含这些版本，以及可查看的固定外貌和固定身材。脸和身材标成「跨世界不变」。

## 测试

- 全局草稿返回并截断新字段，缺少姓名时失败。
- 世界主角草稿包含同一组生活细节；文本生成失败时新字段为空，原有兜底仍可用。
- 适配改写可变项，外貌和身材保持原文；缺字段时保留对应默认值；调用失败时全部回到默认值。
- 正文要求包含新的本世界细节，并要求脸和身材保持固定。
- 角色库页面能看到两组标题和「随世界变化」。
- 开局适配在服装未变时不增加图片修订号，服装变化且图片为自动生成时才清空自动定妆图。
